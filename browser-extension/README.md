# Command Center — Pixel Agents extension

Небольшое read-only расширение для Google Chrome и Brave. Иконка в панели
браузера открывает компактное окно существующего Pixel Agents Office и даёт
быструю ссылку на полный Command Center.

## Что важно

- Расширение не содержит токенов и не обращается к приватным API.
- Оно не запускает, не останавливает и не изменяет задачи.
- Офис исключён из клавиатурной навигации и закрыт прозрачным read-only слоем.
- Pixel Office загружается из того же публичного визуального слоя, который уже
  встроен в Command Center, в защищённом iframe без кликов. Расширение не создаёт
  отдельное состояние агентов и не становится ещё одним источником данных.
- Полный Command Center открывается отдельно по адресу
  `https://command.meshly.fr/?tab=agents`.

## Локальная установка

### Google Chrome

1. Открой `chrome://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение».
4. Выбери папку `browser-extension`.
5. Закрепи иконку `Pixel Agents` в панели браузера.

### Brave

Повтори те же шаги на странице `brave://extensions`.

## Проверка

После установки нажми на pixel-иконку. В popup должен появиться офис с
движущимися агентами. Кнопка «Открыть Command Center» открывает полный экран
агентов в новой вкладке.

## Безопасность

Manifest V3 не запрашивает browser permissions или host permissions. CSP
разрешает только локальный JavaScript расширения и два публичных read-only
адреса: Pixel Office и Command Center. Сам iframe исключён из Tab-навигации,
а прозрачный слой блокирует мышь. Если офис недоступен, popup показывает
локальную безопасную заглушку.
