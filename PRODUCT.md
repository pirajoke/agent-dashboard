# Product

## Register

product

## Users

Mark is the primary operator. He uses the Command Center on desktop and mobile to understand which projects and departments are active, which agents are working, what is blocked, and what requires his approval. The interface must remain useful at a glance and must not require reading technical logs.

## Product Purpose

The Command Center is the visual control plane for MAIN MANAGER. It groups the portfolio into seven departments, routes work to short-lived specialist teams, and projects their real task state into a shared Pixel Verse campus. Success means Mark can understand current work, evidence, and the next decision from one place while agents coordinate in the background.

## Brand Personality

Friendly, trustworthy, quietly playful. The product should feel like a professional working campus with pixel-art character, not a toy and not an enterprise monitoring console.

## Anti-references

- Cyberpunk command centers with constant neon, visual alarm fatigue, or decorative data.
- Corporate dashboards made from interchangeable metric cards and technical jargon.
- Simulations that show fictional activity, permanent busy agents, or movement disconnected from real events.
- Interfaces that expose merge, deploy, credential, payment, or publishing controls before safe owner-only paths exist.

## Design Principles

- Show real work only: every active character maps to a current task or event.
- Departments organize responsibility; temporary teams perform the work.
- Make the next decision obvious without exposing private task content.
- Treat evidence and honest waiting states as first-class product information.
- Spend no model tokens on idle animation or decorative presence.

## Accessibility & Inclusion

Target WCAG 2.2 AA for the new surface. Status must never rely on color alone. Keyboard and touch users must be able to open the same read-only details. All movement must respect `prefers-reduced-motion`, and the static state must remain fully understandable without animation.
