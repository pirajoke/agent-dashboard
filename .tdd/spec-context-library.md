## Module contracts
`dashboard_builder.context_library.build_catalog(vault: Path, previous: dict | None = None, now: str | None = None) -> dict`
Schema 1, `generated_at`, `state` ready|partial|unavailable, `records` list, `sources` list, `issues` list of non-sensitive reason codes. A record: `id` (32 lowercase hex), `kind` transcript|update, `source` plaud|krisp|granola|other|project-update, `source_id` string or empty, `title`, `date` (source date or empty), `modified_at` ISO UTC, `project` string or empty (only declared metadata), `relative_path`, `obsidian_url`, `sha256`, `body` original Markdown. Never infer project from a name. Sources report `observed` or `not_observed`; observation alone never proves active import.
Allowlisted transcript roots only: `10-Transcripts`, `00-Inbox/plaud`, `00-Inbox/krisp`, `00-Inbox/granola`. Updates only `90-Operations/project-update-webhook/logs`. Markdown only. No symlink traversal, dot folders, or files >2 MiB; no general vault scan. Missing vault: unavailable. Missing optional source: honest not_observed. Limit 2000 records, mark partial rather than silently complete. Frontmatter scalars via stdlib; IDs plaud_id/meeting_id/granola_id/writeback_id; source inferred from known directory/name if scalar absent. Identity source+upstream ID when available, otherwise prior matching path, then prior unique body hash for moved notes, otherwise path hash. Duplicate same upstream ID+same body -> one entry; conflicting bodies -> keep both with distinct IDs and partial/conflict issue. Each export body includes original content, source date, observed timestamp and Obsidian link.

`export_catalog(catalog: dict, output: Path, state: Path) -> dict`
Writes managed `Транскрипты/YYYY/<readable-name>.txt`, `Обновления/YYYY/<readable-name>.txt` (unknown year -> `Без даты`), `00 — Каталог.csv`, `00 — Последние обновления.txt`. Manifest outside Drive keeps record ID -> path/hash. Must use previous path when date changes; never duplicate due to rename/date/title change. Stable filenames, no rewriting unchanged bytes. Update own files only when their previous hash matches; unknown or user-edited destination is conflict and preserved. No deletion, missing source never prunes. Atomic same-dir writes, exclusive lock and validate all paths without following symlinks. Missing output or state parent fail closed; source unavailable -> no writes. Catalog body never executed or rendered as HTML. No external model or network calls.

`context_library_projection(path: Path, owner: bool=False, query: str='', source: str='', kind: str='', record_id: str|None=None, now: str|None=None) -> dict`
Read persisted private catalog (max32 MiB) only after owner true. Anonymous -> `{state:'owner_required', records:[]}` with no stat/read. Missing/corrupt catalog -> unavailable with empty records. Index strips `body`, `relative_path`, `source_id`, shows metadata and safe Obsidian URI. Search title/body/project, case insensitive, filter kind/source, max100 entries with total. Detail exact valid id only, includes body as plain text, never arbitrary path. Unknown/malformed id -> not_found, no content. Stale generated_at older than1hour visible as stale; modified_at never masquerades as meeting date. Validate schema and safe local Obsidian URL. API integration GET /api/context-library uses existing strict `_decision_owner_authorized()` and existing `_json_response`; do not modify auth functions or permissions. Catalog file outside served directory, configurable path default HOME/Library/Application Support/Command Center Context/catalog.json.
